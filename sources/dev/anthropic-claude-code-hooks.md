- **저자**: Anthropic

- **매체/학회**: Claude Code 공식 문서
- **링크**: https://code.claude.com/docs/en/hooks
- **유형**: 1차 문헌
- **확인일**: 2026-10-28

## 핵심 요지

Stop 훅이 턴을 계속 실행하게 하는 동작과 작업의 검증 통과 여부는 구분해야 한다.

## 주요 내용

- `stop_hook_active`는 Stop 훅에 의해 이미 계속 실행 중인지 알린다. 문서는 이 값이나 transcript를 확인하여 해소 불가능한 조건을 반복 차단하지 않도록 안내한다.
- 확인 당시 문서는 연속 8회 이후 다음 차단을 해제하는 상한과 도구 호출 시 횟수 초기화를 설명한다. 이 상한은 검증의 통과 판정이 아니다.
- `decision: "block"`은 에이전트의 정지를 막는다. 실제 재진입·종료 처리는 버전과 설정에 맞춰 확인하고, 중단되더라도 미통과 결과를 별도로 보존하는 것은 위키의 게이트 설계 제안이다.
