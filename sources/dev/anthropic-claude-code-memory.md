# Anthropic — How Claude remembers your project

- **저자**: Anthropic
- **연도**: 2026년 확인 당시 문서이며 최초 발행일은 확인하지 못했다.
- **매체/학회**: Claude Code 공식 문서
- **링크**: https://code.claude.com/docs/en/memory
- **유형**: 1차 문헌
- **확인일**: 2026-10-28

## 핵심 요지

상시 지침에는 매 세션에 필요한 규약을 담고, 여러 단계의 절차나 일부 경로에서만 필요한 지침은 용도에 맞게 분리한다.

## 주요 내용

- 문서는 `CLAUDE.md`에 빌드 명령·규약·프로젝트 구조 등 매 세션에 필요한 정보를 유지하도록 안내한다. 여러 단계의 절차는 스킬, 일부 경로에만 필요한 지침은 경로별 규칙으로 옮길 수 있다.
- 문서 위치에 따라 적용 범위와 로딩 시점이 다르다. 하위 디렉토리 지침을 모두 시작 시점에 읽는다고 가정하지 않는다.
- 일시적인 목표·블로커를 작업 문서나 handoff로 분리하는 것은 이 안내를 바탕으로 한 위키의 운용 제안이다.
