# Anthropic — Create custom subagents

- **저자**: Anthropic
- **연도**: 2026년 확인 당시 문서이며 최초 발행일은 확인하지 못했다.
- **매체/학회**: Claude Code 공식 문서
- **링크**: https://code.claude.com/docs/en/sub-agents
- **유형**: 1차 문헌
- **확인일**: 2026-10-28

## 핵심 요지

중첩 생성과 대화 상속은 별개의 실행 조건이다. 별도 에이전트라는 이유만으로 새 맥락이나 특정 중첩 제한을 보장하지 않는다.

## 주요 내용

- 확인 당시 문서는 기본적으로 메인 대화 아래 3계층의 서브에이전트 생성을 허용하며, 설정과 도구 권한으로 제한할 수 있다고 설명한다. 다른 제품·버전의 한도로 일반화하지 않는다.
- 일반 서브에이전트는 새 맥락에서 시작하지만 fork는 부모 대화를 상속한다. 독립 검증을 설계할 때는 실제 상속 방식과 전달할 정보를 확인한다.
- 이러한 실행 구조만으로 검증자의 정확성이나 공정성을 보장하지는 않는다.
