## 핵심 요지

고정된 Hermes 하네스의 소프트웨어 작업 40개에서 Daybreak Blue 접근 조건이
일반 GPT-5.6 Sol 접근 조건보다 높은 해결률을 보였다고 보고한다. 작성자는 이를
서로 다른 모델 가중치나 보편적 능력 격차의 증거로 해석하지 않는다.

## 주요 내용

- 주 비교는 40개 작업과 6개 접근 조건의 첫 시도 240회다. 10개 작업의 추가
  반복 120회를 포함해 전체 360회를 실행했다고 보고한다.
- 동일한 작업·초기 저장소·하네스·도구·시간 제한과 `high` 추론 수준을 사용했다.
- Daybreak Blue는 37/40(92.5%), 일반 GPT-5.6 Sol은 32/40(80.0%)을 해결했다.
  둘 다 해결한 작업은 32개, 둘 다 실패한 작업은 3개, Blue만 해결한 작업은 5개다.
- 두 조건은 같은 GPT-5.6 Sol 기반 스냅샷으로 선언돼 있다. 작성자는 서버의
  불변 가중치를 독립적으로 입증하지 못했다고 명시한다.
- 대응 비교의 양측 McNemar 검정값은 `p=0.0625`이며 통상적인 0.05 기준을
  충족하지 않는다. 고정된 소규모 작업 집합의 결과를 모집단 우위로 일반화하지 않는다.
- Codex CLI 자체 또는 GPT-6.1 Sol과의 비교가 아니다. 공개 결과에는 원시 모델
  응답이 포함되지 않는다고 명시한다. 이번 수록에서는 재현과 무결성 검증을 수행하지 않았다.
