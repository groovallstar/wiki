## 핵심 요지

Ubiquitous language는 하나의 bounded context 안에서 팀의 활동과 소프트웨어를 연결하는 도메인 모델 기반 언어다.

## 주요 내용

- 정의와 Bounded Context·Ubiquitous Language 절은 모델과 용어의 유효 범위를 명시한다. 조직 전체에 하나의 의미를 강제하는 개념으로 해석하지 않는다.
- 같은 문맥의 문서·대화·코드에서 공유 언어를 일관되게 사용한다. 서로 다른 모델의 문맥 경계와 대응 관계는 구분한다.
