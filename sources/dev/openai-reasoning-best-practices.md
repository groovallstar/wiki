# OpenAI — Reasoning best practices

- **저자**: OpenAI
- **연도**: 2026년 확인 당시 문서이며 최초 발행일은 확인하지 못했다.
- **매체/학회**: OpenAI API 공식 문서
- **링크**: https://developers.openai.com/api/docs/guides/reasoning-best-practices
- **유형**: 1차 문헌
- **확인일**: 2026-10-28

## 핵심 요지

추론 모델에는 명확한 목표·제약을 주고 예시 없이 먼저 시도하되, 복잡한 요구에서는 입력·정답 예시의 효과를 확인한다.

## 주요 내용

- 간단하고 직접적인 지시, 명확한 구분자, 구체적인 제약과 성공 기준을 권장한다.
- 내부적으로 추론하므로 사고 과정을 단계별로 지시할 필요가 없으며 일부 상황에서는 성능에 방해가 될 수 있다고 설명한다.
- zero-shot부터 시도하고 필요하면 few-shot을 활용한다. 예시는 지시와 일치해야 하며, 용도를 형식·톤으로만 한정하지 않는다.
- 특정 프롬프트 기법의 효과를 모든 모델·작업에 보장하는 설명은 아니다.
