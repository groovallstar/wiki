## 카탈로그 개요

AI 코딩 에이전트와 사람이 공유하는 4대 실패 모드(정렬 부족·장황함·코드가 안
돎·진흙 공) 에 각각 대응하는 process-driven skill 모음. 각 스킬은 `SKILL.md`
파일에 frontmatter(name·description·trigger) 와 본문(절차·체크리스트) 을
담는다. 저장소 루트의 `README.md`·`CLAUDE.md`·`CONTEXT.md` 가 카탈로그
공통 어휘와 운영 원칙을 정의한다.

## 위키와 직접 관련된 스킬

  어휘집) 운영을 4단계로 정식화: Challenge / Sharpen / Cross-reference /
